# Original Poster Author (theme component)

In the configured categories, topic lists show the avatar of the **original poster**
instead of the last poster. Other categories are untouched.

Covers: desktop "posters" column, mobile topic-list avatar, and the "latest topics"
list on the categories page.

Setting `op_author_categories`: category paths, default `community/racconti`
(subcategories included). Add the component to the active theme.
